# president-gostudy
## 概要
Websocket勉強用
3人プレイを想定したトランプゲームの大富豪を作成する
フロントエンドはhtml+js
バックエンドはgolangを使用する
## 処理概要
### バックエンド
ルーム待機用のサーバーとゲーム通信用のサーバーの２種構成
クライアントサーバー間通信はWebSocket、サーバー間通信はgRPCを使用する
#### ルームサーバ
WebSocketの接続後プレイヤーIDを受信しルームの作成、もしくは既存の待機ルームへの追加を行う
待機中プレイヤーの変動やゲーム開始などを随時通知する
ルームの待機人数が満た場合ゲームサーバーにルームのプレーヤーIDを送信し接続トークンとルームIDを受け取り
クライアントにゲームサーバーのURLと合わせて送信する
クライアントがゲームサーバーへ接続できたことが確認出来たら接続を切る
#### ゲームサーバー
ルームサーバーからルームのプレーヤーIDを受信すると接続するPlayerのIDを基にルームを作成し制限時間付きの接続トークンとルームIDを発行する
プレイヤーの接続が確認できるとルームサーバーに通知する
ゲームが開始するとゲームの流れに沿って各プレイヤーへのターン開始の通知やターンの行動の受信とそれに基づいたゲームデータの更新、現在のターンのプレイヤーを格納し他プレイヤーの行動をブロックするなど合わせて実装する
